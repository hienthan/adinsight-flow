Privacy Policy –

Effective date: November 11, 2026

Who uses this application

is a private tool used only by its owner to manage and report on the owner's own Google Ads account. It is not offered to the public and has no other users.

Data accessed

With the owner's consent through Google OAuth, the application uses the Google Ads API scope (https://www.googleapis.com/auth/adwords) to read campaign performance data (such as cost, clicks, conversions and search terms) and to make changes the owner explicitly approves in the owner's own Google Ads account.

How data is used and stored

  • Data is used only to show reports and carry out changes for the owner.
  • OAuth tokens and data are stored only on the owner's own computer.
  • No data is sold, shared with or transferred to any third party.
  • No data is used for advertising, profiling or training of any model.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Revoking access stops all further data access; locally stored tokens can then be deleted.
