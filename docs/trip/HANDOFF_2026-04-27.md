## 2. zh Title / Translation Bug

Confirmed bug:

- many Trip rows still showed zh titles in GUI
- root cause was cache poisoning in `scripts/trip/lib/translation.py`
- unusable CJK fallback output had been cached as if it were a valid EN translation

Fix already applied:

- cache reuse is now gated by translation usability
- CJK fallback is no longer treated as a valid EN translation
- final GUI titles should follow the Klook-style flow:
  1. decode slug/path
  2. translate zh -> EN
  3. classify with both zh + EN text
  4. generate final EN title

Important:

- old classified JSON and old PocketBase imports still reflect pre-fix data
- full reclassification and reimport are required before trusting title quality in GUI
